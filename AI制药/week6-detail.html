Day 1：图论基础 + 分子→图表示

⏱️ 1.5小时 · 🎯 能把任何SMILES转成PyG图数据对象

理解图的基本概念

  • 节点(Node/Vertex)：图中的点。分子中=原子
  • 边(Edge)：连接两个节点的线。分子中=化学键
  • 邻接矩阵：N×N矩阵，A[i][j]=1表示节点i和j之间有边
  • 节点特征：每个节点的属性向量。原子特征=原子序数/杂化状态/手性/电荷/芳香性/氢原子数
  • 边特征：每条边的属性向量。键特征=键类型(单/双/三/芳香)/共轭/环内

RDKit→PyG Data 转换函数（今天最重要的代码）

import torch; from torch_geometric.data import Data
from rdkit import Chem

def smiles_to_pyg_data(smiles):
    mol = Chem.MolFromSmiles(smiles)
    if mol is None: return None

    # 节点特征：每个原子的属性
    atom_features = []
    for atom in mol.GetAtoms():
        feats = [
            atom.GetAtomicNum(),           # 原子序数
            atom.GetDegree(),              # 连接数
            atom.GetFormalCharge(),        # 形式电荷
            int(atom.GetHybridization()),    # 杂化状态
            int(atom.GetIsAromatic()),       # 芳香性
            atom.GetTotalNumHs(),          # 氢原子数
        ]
        atom_features.append(feats)

    # 边索引（连接关系）
    edge_index = []
    edge_attr = []
    for bond in mol.GetBonds():
        i, j = bond.GetBeginAtomIdx(), bond.GetEndAtomIdx()
        edge_index.append([i, j]); edge_index.append([j, i])  # 无向图=双向边
        bt = bond.GetBondTypeAsDouble()
        edge_attr.extend([[bt], [bt]])

    x = torch.tensor(atom_features, dtype=torch.float)
    ei = torch.tensor(edge_index, dtype=torch.long).t().contiguous()
    ea = torch.tensor(edge_attr, dtype=torch.float)

    return Data(x=x, edge_index=ei, edge_attr=ea)
✅ 给SMILES→输出PyG Data(含x节点特征+edge_index边索引+edge_attr边特征)

Day 2：消息传递范式 + GCN

⏱️ 1.5小时 · 🎯 理解消息传递三步骤，跑通第一个GCN

消息传递三步骤

  1. 消息(Message)：每个邻居发一条消息(通常是邻居特征×权重)
  2. 聚合(Aggregate)：汇总所有邻居消息(mean/sum/max)
  3. 更新(Update)：用汇总消息更新当前节点表示

GCN的本质：我的新特征 = 我自己的特征 + 所有邻居特征的加权平均。多层堆叠=信息在图中传播越来越远。

第一个GCN模型

from torch_geometric.nn import GCNConv
class MolGCN(nn.Module):
    def __init__(self, in_dim, hidden=128):
        super().__init__()
        self.conv1 = GCNConv(in_dim, hidden)
        self.conv2 = GCNConv(hidden, hidden)
        self.fc = nn.Linear(hidden, 1)
    def forward(self, data):
        x, ei = data.x, data.edge_index
        x = torch.relu(self.conv1(x, ei))
        x = torch.relu(self.conv2(x, ei))
        x = x.mean(dim=0, keepdim=True)  # 全局池化→图级别表示
        return self.fc(x)

Day 4：MPNN——分子性质预测的标准框架

MPNN 把消息传递和读出分成两个阶段。核心区别在读出(Readout)：

  • sum：保留总量信息（分子量相关的性质）
  • mean：对图大小不敏感
  • max：保留最强信号
  • set2set：注意力加权汇总（最灵活，通常最好）

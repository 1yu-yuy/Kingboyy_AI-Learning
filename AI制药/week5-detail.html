Day 2：Autograd——PyTorch的核心魔法

⏱️ 1.5小时 · 🎯 理解自动微分，能求任意函数的梯度

理解 Autograd——这改变了深度学习

# 手写 y=x³+2x 在 x=2 处的导数
# 数学：dy/dx = 3x²+2 = 3×4+2 = 14
x = torch.tensor([2.0], requires_grad=True)
y = x**3 + 2*x
y.backward()
print(f"PyTorch自动求导: {x.grad.item()}")  # 应输出14.0

关键概念：

  • requires_grad=True：告诉PyTorch"我要对这个变量求导"
  • backward()：自动计算所有 requires_grad=True 的变量的梯度
  • .grad：存梯度值（每次 backward 会累加——所以要 zero_grad）
  • 动态计算图：每次 forward 都重新构建图——这是 PyTorch 和 TensorFlow 1.x 的最大区别

练习：求偏导数

# f(x,y) = x²y + sin(xy)，求在(1,2)处的梯度
x = torch.tensor([1.0], requires_grad=True)
y = torch.tensor([2.0], requires_grad=True)
f = x**2 * y + torch.sin(x*y)
f.backward()
print(f"∂f/∂x = {x.grad.item():.4f}")  # 2×1×2+2×cos(2)=4-0.832=3.168
print(f"∂f/∂y = {y.grad.item():.4f}")  # 1²+1×cos(2)=1-0.416=0.584
✅ 理解 requires_grad/backward/grad/zero_grad 四个关键概念

import torch; import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset

# 1. 准备数据
X_t = torch.tensor(X_train, dtype=torch.float32)
y_t = torch.tensor(y_train, dtype=torch.float32).reshape(-1,1)
dataset = TensorDataset(X_t, y_t)
loader = DataLoader(dataset, batch_size=32, shuffle=True)

# 2. 定义模型
class MolNet(nn.Module):
    def __init__(self, in_dim, hidden=128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, hidden), nn.ReLU(), nn.Dropout(0.2),
            nn.Linear(hidden, hidden//2), nn.ReLU(), nn.Dropout(0.2),
            nn.Linear(hidden//2, 1)
        )
    def forward(self, x):
        return self.net(x)

model = MolNet(in_dim=X.shape[1])
loss_fn = nn.MSELoss(); optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# 3. 训练循环
for epoch in range(100):
    model.train()
    for xb, yb in loader:
        pred = model(xb)
        loss = loss_fn(pred, yb)
        optimizer.zero_grad()       # 清零上次梯度
        loss.backward()              # 反向传播
        optimizer.step()             # 更新权重
    if (epoch+1) % 20 == 0:
        print(f"Epoch {epoch+1} Loss={loss.item():.4f}")

Day 4：CNN基础——卷积操作及其在分子中的应用

⏱️ 1.5小时 · 🎯 理解卷积核/步长/填充/池化

核心概念可视化

  • 卷积核(kernel)：滑动窗口，对局部区域做加权求和——检测局部模式
  • 步长(stride)：窗口每次滑多远。步长>1 → 降采样
  • 填充(padding)：边缘补0——控制输出尺寸。padding=kernel//2 → 输出和输入同尺寸
  • 池化(pooling)：降采样保留最强信号——MaxPool/MeanPool

1D CNN 处理 SMILES 序列

class SMILES_CNN(nn.Module):
    def __init__(self, vocab_size, embed_dim=64):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, embed_dim)
        self.conv1 = nn.Conv1d(embed_dim, 128, kernel_size=3, padding=1)
        self.conv2 = nn.Conv1d(128, 256, kernel_size=5, padding=2)
        self.pool = nn.AdaptiveMaxPool1d(1)
        self.fc = nn.Linear(256, 1)
    def forward(self, x):
        x = self.embed(x).transpose(1,2)  # (B,L,E)→(B,E,L)
        x = torch.relu(self.conv1(x)); x = torch.relu(self.conv2(x))
        x = self.pool(x).squeeze(-1)
        return self.fc(x)

Day 5：RNN/LSTM——序列建模的工具

⏱️ 1.5小时 · 🎯 理解LSTM门控机制

LSTM三门的直觉理解

  • 遗忘门(Forget Gate)：决定丢掉哪些旧信息。sigmoid→0~1，0=全忘
  • 输入门(Input Gate)：决定存入哪些新信息。sigmoid控制"开关"+tanh生成"候选值"
  • 输出门(Output Gate)：决定输出哪些信息。基于当前细胞状态过滤

Day 1：RDKit 入门——在Python里读分子、画分子

⏱️ 1.5小时 · 🎯 安装RDKit，理解SMILES，能画分子结构图

什么是 RDKit？

RDKit 是化学信息学领域最流行的开源工具包。它可以：读分子（从SMILES/SDF/MOL）→ 算描述符（200+种）→ 画结构图 → 做分子指纹 → 化学反应处理 → 构象分析。几乎所有 AI 制药项目的分子预处理都离不开它。

第2步：理解 SMILES——分子的"字符串身份证"

SMILES（Simplified Molecular Input Line Entry System）是把分子结构写成一行字符串的方法。每个分子有唯一的 SMILES（规范化的）。

# 几个常见药物的 SMILES
aspirin   = 'CC(=O)Oc1ccccc1C(=O)O'   # 阿司匹林
ibuprofen = 'CC(C)Cc1ccc(C(C)C(=O)O)cc1' # 布洛芬
caffeine  = 'CN1C=NC2=C1C(=O)N(C(=O)N2C)C' # 咖啡因
paracetamol = 'CC(=O)Nc1ccc(O)cc1'      # 对乙酰氨基酚（扑热息痛）

去哪找 SMILES？→ pubchem.ncbi.nlm.nih.gov，搜索药名，页面上就有 Canonical SMILES。

💡 SMILES 语法速成：大写字母=原子(C/N/O)；小写字母=芳香环中的原子(c/n/o)；= 双键；# 三键；() 分支；数字=开环/闭环标记。如 c1ccccc1=苯环。

第3步：从 SMILES 创建分子对象，算基本信息

from rdkit import Chem
from rdkit.Chem import Descriptors

# 创建分子对象
mol = Chem.MolFromSmiles('CC(=O)Oc1ccccc1C(=O)O')
# 如果SMILES不合法，mol会是None——一定要检查！
if mol is None:
    print("❌ SMILES不合法")
else:
    print("✅ 分子创建成功")
    print(f"分子量: {Descriptors.MolWt(mol):.2f} g/mol")
    print(f"LogP: {Descriptors.MolLogP(mol):.2f}")
    print(f"分子式: {Chem.rdMolDescriptors.CalcMolFormula(mol)}")
    print(f"氢键供体数: {Descriptors.NumHDonors(mol)}")
    print(f"氢键受体数: {Descriptors.NumHAcceptors(mol)}")
    print(f"可旋转键数: {Descriptors.NumRotatableBonds(mol)}")
    print(f"TPSA: {Descriptors.TPSA(mol):.1f} Å²")
    print(f"重原子数: {mol.GetNumHeavyAtoms()}")
✅ 验收：能输出分子量180.16（阿司匹林）、LogP约1.2、分子式C9H8O4

Day 2：分子描述符 + 分子指纹——把分子变成数字

⏱️ 1.5小时 · 🎯 从分子提取 200+ 描述符和 ECFP4 指纹，理解 Tanimoto 相似度

为什么要把分子变成数字？

机器学习模型只认识数字。分子→描述符/指纹=把化学结构转成特征向量→ML模型才能"看懂"分子。

第1步：单描述符计算——理解每个指标的化学含义

from rdkit import Chem
from rdkit.Chem import Descriptors

mol = Chem.MolFromSmiles('CC(=O)Oc1ccccc1C(=O)O')  # 阿司匹林

# 最常用的6个描述符（药物化学必看）
print(f"分子量 MolWt: {Descriptors.MolWt(mol):.1f} g/mol")
print(f"脂水分配系数 MolLogP: {Descriptors.MolLogP(mol):.2f}")
print(f"氢键供体数 NumHDonors: {Descriptors.NumHDonors(mol)}")
print(f"氢键受体数 NumHAcceptors: {Descriptors.NumHAcceptors(mol)}")
print(f"可旋转键数 NumRotatableBonds: {Descriptors.NumRotatableBonds(mol)}")
print(f"拓扑极性表面积 TPSA: {Descriptors.TPSA(mol):.1f} Å²")

# Lipinski 五规则检查——判断分子是否"像药"
mw = Descriptors.MolWt(mol)
logp = Descriptors.MolLogP(mol)
hbd = Descriptors.NumHDonors(mol)
hba = Descriptors.NumHAcceptors(mol)
violations = sum([mw > 500, logp > 5, hbd > 5, hba > 10])
print(f"\nLipinski违规数: {violations}（≤1为类药分子）")
💡 Lipinski 五规则（Rule of 5）：口服药物通常满足 MW<500, LogP<5, HBD<5, HBA<10。违反≤1条=类药性好。这是药物化学最经典的规则之一。

第2步：批量计算 200+ 个描述符

from rdkit.Chem import Descriptors

# 获取所有可用描述符的名字
desc_names = [name for name, func in Descriptors._descList]
print(f"共 {len(desc_names)} 个描述符可用")  # 约210个

# 对单个分子计算所有描述符
def calc_all_descriptors(mol):
    """返回所有描述符的列表"""
    descs = []
    for name in desc_names:
        try:
            val = getattr(Descriptors, name)(mol)
            descs.append(val)
        except:
            descs.append(None)  # 有些描述符对特定分子无法计算
    return descs

mol = Chem.MolFromSmiles('CC(=O)Oc1ccccc1C(=O)O')
desc_values = calc_all_descriptors(mol)
print(f"计算了 {len(desc_values)} 个描述符")
print(f"其中 {desc_values.count(None)} 个无法计算")

第3步：分子指纹 ECFP4（最核心的概念）

分子指纹 = 把分子的子结构编码成固定长度的二进制向量。ECFP4（Extended-Connectivity Fingerprints, diameter 4）是最常用的。

from rdkit.Chem import AllChem
from rdkit import DataStructs

mol = Chem.MolFromSmiles('CC(=O)Oc1ccccc1C(=O)O')

# 生成 Morgan 指纹（= ECFP）
# radius=2 → 直径4 → ECFP4
# nBits=1024 → 1024位二进制向量
fp = AllChem.GetMorganFingerprintAsBitVect(mol, radius=2, nBits=1024)
print(f"指纹长度: {len(fp)} 位")
print(f"其中为1的位数: {sum(fp)}")  # 通常占总位数的5-15%
print(f"前20位: {fp.ToBitString()[:50]}...")

# 也可以用 MACCS 指纹（167位，基于预定义的子结构键）
from rdkit.Chem import MACCSkeys
maccs = MACCSkeys.GenMACCSKeys(mol)
print(f"\nMACCS指纹: {len(maccs)} 位, {sum(maccs)} 个为1")
💡 ECFP4 vs MACCS：ECFP4 基于圆形邻域（通用，适合ML），MACCS 基于预定义的 166 个子结构（可解释性强）。大多数 ML 项目用 ECFP4。

第4步：Tanimoto 相似度——两个分子有多像？

# 比较阿司匹林 vs 布洛芬的相似度
mol1 = Chem.MolFromSmiles('CC(=O)Oc1ccccc1C(=O)O')   # 阿司匹林
mol2 = Chem.MolFromSmiles('CC(C)Cc1ccc(C(C)C(=O)O)cc1') # 布洛芬
mol3 = Chem.MolFromSmiles('CC(=O)Nc1ccc(O)cc1')       # 扑热息痛

fp1 = AllChem.GetMorganFingerprintAsBitVect(mol1, 2, 1024)
fp2 = AllChem.GetMorganFingerprintAsBitVect(mol2, 2, 1024)
fp3 = AllChem.GetMorganFingerprintAsBitVect(mol3, 2, 1024)

sim_12 = DataStructs.TanimotoSimilarity(fp1, fp2)
sim_13 = DataStructs.TanimotoSimilarity(fp1, fp3)
sim_23 = DataStructs.TanimotoSimilarity(fp2, fp3)

print(f"阿司匹林 vs 布洛芬:   {sim_12:.3f}")  # 预计0.1-0.3
print(f"阿司匹林 vs 扑热息痛: {sim_13:.3f}")  # 预计0.2-0.4
print(f"布洛芬 vs 扑热息痛:   {sim_23:.3f}")

# Tanimoto 取值 0（完全不相似）到 1（完全相同）
# 同类药物通常 >0.3，骨架相似的 >0.5

第5步：练习——5个药物的描述符矩阵 + 相似度矩阵

# 选5个药物，构建描述符矩阵和相似度矩阵
drugs_smiles = {
    '阿司匹林': 'CC(=O)Oc1ccccc1C(=O)O',
    '布洛芬': 'CC(C)Cc1ccc(C(C)C(=O)O)cc1',
    '扑热息痛': 'CC(=O)Nc1ccc(O)cc1',
    '咖啡因': 'CN1C=NC2=C1C(=O)N(C(=O)N2C)C',
    '奥美拉唑': 'CC1=CN=C(C(=C1OC)C)CSC2=NC3=C(N2)C=C(C=C3)OC',
}

mols = {name: Chem.MolFromSmiles(s) for name, s in drugs_smiles.items()}
fps = {name: AllChem.GetMorganFingerprintAsBitVect(m, 2, 1024) for name, m in mols.items()}

# 构建相似度矩阵
names = list(drugs_smiles.keys())
sim_matrix = np.zeros((5, 5))
for i in range(5):
    for j in range(5):
        sim_matrix[i, j] = DataStructs.TanimotoSimilarity(fps[names[i]], fps[names[j]])

print("相似度矩阵:")
print(pd.DataFrame(sim_matrix, index=names, columns=names).round(3))

# 找最相似的一对（忽略对角线）
sim_triu = np.triu(sim_matrix, k=1)
max_idx = np.unravel_index(sim_triu.argmax(), sim_triu.shape)
print(f"\n最相似: {names[max_idx[0]]} vs {names[max_idx[1]]} ({sim_matrix[max_idx]:.3f})")
✅ 今日验收：能算描述符和 ECFP4 指纹，理解 Tanimoto 相似度，能构建相似度矩阵

Day 3：ChEMBL 数据库——获取真实的药物数据

⏱️ 1.5小时 · 🎯 用 Python API 从 ChEMBL 获取化合物和活性数据

第1步：理解 ChEMBL——全球最大的公开药物数据库

ChEMBL 由欧洲生物信息学研究所(EBI)维护，收录了数百万化合物的生物活性数据。是 AI 制药研究最常用的数据源。

数据层级：Target(靶点，如 EGFR) → Assay(实验方法) → Activity(活性值：IC50/Ki/Kd/EC50) → Molecule(化合物 + SMILES)

第3步：搜索靶点

print(f"找到 {len(results)} 个相关靶点")

    print(f"  {r['target_chembl_id']:20s} {r.get('pref_name','N/A'):30s} {r.get('organism','')}")

# 选人类EGFR: CHEMBL203（通常第一个就是）
target_id = 'CHEMBL203'

第4步：获取活性数据——最核心的操作

# 获取 IC50 数据（半数抑制浓度——衡量药物效力的标准指标）
acts = activity.filter(
    target_chembl_id=target_id,
    standard_type='IC50'  # 只取IC50活性值
).only([
    'molecule_chembl_id',
    'canonical_smiles',
    'standard_value',
    'standard_units',
    'standard_relation'
])[:500]  # 限制500条，避免超时

print(f"获取了 {len(acts)} 条 IC50 数据")
print(f"示例: {acts[0]}")

第5步：转成 DataFrame 并清洗保存

import pandas as pd

df = pd.DataFrame(acts)
print(f"原始数据: {len(df)} 条")

# 关键清洗步骤
df['standard_value'] = pd.to_numeric(df['standard_value'], errors='coerce')
df = df.dropna(subset=['standard_value', 'canonical_smiles'])
print(f"清洗后: {len(df)} 条")

# IC50 越小活性越高 → 转 pIC50 = -log10(IC50) 让它越大越好
# IC50单位通常是nM，先统一转成M：IC50(M) = IC50(nM) × 10⁻⁹
df['pIC50'] = -np.log10(df['standard_value'] * 1e-9)

print(f"pIC50 范围: {df['pIC50'].min():.1f} ~ {df['pIC50'].max():.1f}")
print(f"pIC50 均值: {df['pIC50'].mean():.1f}")

# 保存
df.to_csv('egfr_ic50_data.csv', index=False)
print("✅ 数据已保存")
💡 pIC50 是什么？ pIC50 = -log₁₀(IC50)。IC50=1nM → pIC50=9；IC50=1μM → pIC50=6。值越大活性越强。这样做回归时"大=好"。

Day 4：制药工艺数据——理解批次数据的特点

⏱️ 1.5小时 · 🎯 理解工艺数据结构，能用 Python 处理批次×参数×时间多维数据

核心认知

制药工艺数据 = 三维结构（批次 × 工艺参数 × 时间）。每一批生产会产生：

  • 工艺参数：温度曲线、pH变化、搅拌转速、加料速率、各步骤持续时长
  • 中间体检测：IPC（过程控制）检测值——反应终点判断
  • 最终质量：收率、纯度、粒径分布、晶型、残留溶剂

构造50批模拟工艺数据

import numpy as np; import pandas as pd
np.random.seed(42)

n = 50  # 50个批次
df = pd.DataFrame({
    'batch_id': [f'B{i:03d}' for i in range(1, n+1)],
    '产品': np.random.choice(['A药','B药','C药'], n),
    '反应温度_C': np.random.normal(60, 3, n),
    '结晶温度_C': np.random.normal(5, 1.5, n),
    'pH': np.random.normal(7.0, 0.3, n),
    '搅拌转速_rpm': np.random.normal(300, 20, n),
    '反应时间_h': np.random.normal(8, 0.5, n),
    '结晶时间_h': np.random.normal(4, 0.3, n),
})
# 添加相关关系：温度↑→收率↑但纯度↓（真实工艺中的权衡）
df['收率_%'] = 85 + (df['反应温度_C']-60)*0.4 + np.random.normal(0, 3, n)
df['纯度_%'] = 99.5 - (df['反应温度_C']-60)*0.02 + np.random.normal(0, 0.2, n)
df['收率_%'] = df['收率_%'].clip(70, 98)
df['纯度_%'] = df['纯度_%'].clip(98.5, 100)

print(df.describe())
print(f"\n数据形状: {df.shape} — {n}批 × {len(df.columns)}列")

批次间对比分析

# 收率最差的3批——调查原因
worst = df.nsmallest(3, '收率_%')
print("收率最低的3批:")
print(worst[['batch_id','反应温度_C','pH','收率_%','纯度_%']])

# 对比最好 vs 最差批次
best = df.loc[df['收率_%'].idxmax()]
print(f"\n最好批次 ({best['batch_id']}):")
print(f"  温度={best['反应温度_C']:.1f} 收率={best['收率_%']:.1f}% 纯度={best['纯度_%']:.2f}%")
w = df.loc[df['收率_%'].idxmin()]
print(f"\n最差批次 ({w['batch_id']}):")
print(f"  温度={w['反应温度_C']:.1f} 收率={w['收率_%']:.1f}% 纯度={w['纯度_%']:.2f}%")
print(f"\n差异分析：温度差{best['反应温度_C']-w['反应温度_C']:.1f}°C")
✅ 验收：能构造和理解三维工艺数据，知道药厂数据两大特点（批次少+数据脏）

Day 5：GMP 数据合规——AI 在药企的特殊要求

⏱️ 1小时 · 🎯 理解 ALCOA+ 和 21 CFR Part 11，知道 AI 落地药企需要什么

ALCOA+ 原则（药厂数据黄金标准）

AAttributable 可归属谁产生的这个数据？
LLegible 清晰可读能看得懂吗？永久可读？
CContemporaneous 同步当时就记录了吗？不是事后补的？
OOriginal 原始是原始记录还是复制品？
AAccurate 准确数据无误？没有篡改？
+ Complete (完整) + Consistent (一致) + Enduring (持久) + Available (可用)

21 CFR Part 11 对 AI 系统的三大要求

  1. 审计追踪：模型每次预测→记录谁、何时、输入什么、输出什么。变更模型→记录为什么改、改成什么、谁批准的。
  2. 电子签名：对AI输出的关键决策（如判定一批药是否放行）需要有资质的人电子签名确认。
  3. 系统验证(CSV)：需要证明AI系统按照预期工作。模型性能需经过独立验证集的评估并文档化。

这对你的 AI 系统意味着什么

  • 模型必须可解释 → SHAP/LIME/GNNExplainer
  • 模型版本管理 → MLflow/DVC/Git
  • 数据不可篡改 → 只读存储 + 哈希校验
  • 预测结果带置信度 → 不确定性量化（后面会学）

Day 6：综合实战——ChEMBL + RDKit 完整 Pipeline

⏱️ 2小时 · 🎯 走完从数据库到特征矩阵的全流程

Pipeline 流程

  1. ChEMBL 获取 EGFR 靶点 ≥200 个化合物的 SMILES + IC50
  2. RDKit 计算：≥20 个描述符 + ECFP4 指纹(1024位)

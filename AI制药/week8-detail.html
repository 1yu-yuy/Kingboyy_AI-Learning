Day 1：DeepChem——AI制药的一站式框架

5行代码训练ADMET模型

import deepchem as dc
# 1. 加载数据
tasks, datasets, transformers = dc.molnet.load_tox21(featurizer='ECFP')
train, valid, test = datasets
# 2. 创建模型
model = dc.models.MultitaskClassifier(n_tasks=len(tasks), n_features=1024, layer_sizes=[1000])
# 3. 训练
model.fit(train, nb_epoch=10)
# 4. 评估
print(model.evaluate(test, transformers))

Day 3：AlphaFold——蛋白质结构预测革命

AlphaFold 核心思想：MSA(多序列比对)提取进化信息 + Structure Module(IPA注意力)迭代优化3D坐标。

你不用训练AlphaFold——直接去 alphafold.ebi.ac.uk 下载预测好的蛋白结构PDB文件。用PyMOL/NGLview可视化→找到结合口袋→为分子对接做准备。

Day 4：ESMFold + DiffDock——AI分子对接

  • ESMFold：Meta的轻量蛋白预测，适合小蛋白快速预测
  • DiffDock：基于扩散模型的盲对接(不需预定义结合口袋)，输入蛋白+分子→预测最佳结合位姿

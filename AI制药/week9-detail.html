Day 1：问题定义 + 数据准备

选哪个工艺场景？推荐：原料药结晶工艺优化

为什么选结晶？结晶决定了原料药的晶型、粒径、纯度——直接影响制剂和生物利用度。工艺参数多(温度/pH/搅拌/降温速率/晶种量)、目标多样(收率+纯度+粒径)=非常适合ML。

定义输入输出

输入(工艺参数)范围输出(质量指标)目标
结晶温度0~10°C收率最大化
降温速率0.1~1°C/min纯度>99.5%
搅拌转速150~400rpm粒径D5080~120μm
晶种量0.5~3%晶型目标晶型
陈化时间1~6h松密度特定范围

构造300批模拟工艺数据

np.random.seed(42); n = 300
df = pd.DataFrame({
    '结晶温度_C': np.random.uniform(0, 10, n),
    '降温速率_Cpermin': np.random.uniform(0.1, 1.0, n),
    '搅拌转速_rpm': np.random.uniform(150, 400, n),
    '晶种量_pct': np.random.uniform(0.5, 3.0, n),
    '陈化时间_h': np.random.uniform(1, 6, n),
    'pH': np.random.normal(7, 0.3, n),
})
# 加入非线性和交互效应的真实模拟
T = df['结晶温度_C']; S = df['搅拌转速_rpm']
df['收率_%'] = 80 + 2*(T-5) - 0.1*(T-5)**2 + 0.005*(S-275) + np.random.normal(0,3,n)
df['纯度_%'] = 99.5 - 0.02*(T-5)**2 + 0.003*(S-300) + np.random.normal(0,0.2,n)
df['收率_%'] = df['收率_%'].clip(65,97); df['纯度_%'] = df['纯度_%'].clip(98,100)

Day 3：工艺特征工程——注入领域知识

这是你作为制药工程科班生的优势所在！

  • 热处理强度=温度×时间的积分（反映物料受到的总热量）
  • 降温速率²（结晶动力学中速率影响是非线性的）
  • 搅拌功率数=转速²×桨直径⁵（流体力学无量纲数）
  • 过饱和度比=C/C*（结晶驱动力——如果有溶解度数据）

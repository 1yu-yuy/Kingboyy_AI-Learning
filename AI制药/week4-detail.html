Day 1：ADMET 全景 + TDC 数据加载

ADMET 为什么重要？

约40%的临床失败来自ADMET问题——不是药没用，而是吸收不了/代谢太快/有毒。所以 Pharma 在临床前就要预测 ADMET。

字母含义关键指标TDC数据集
Absorption吸收：药能进血液吗？Caco-2渗透性、PAMPACaco2_Wang
Distribution分布：药去了哪些器官？血浆蛋白结合(PPB)、BBB穿透BBB_Martins
Metabolism代谢：被哪个CYP酶分解？CYP3A4/2D6/2C9CYP_P450
Excretion排泄：多快排出体外？清除率(CL)、半衰期(t₁/₂)Half_Life
Toxicity毒性：有毒吗？（头号杀手）hERG心脏毒性、AMES遗传毒性、DILI肝毒性herg_central

Day 2：特征工程深度——从分子到高质量特征矩阵

⏱️ 2小时 · 🎯 提取描述符+指纹，做特征筛选，保存高质量特征矩阵

构建特征提取函数

from rdkit import Chem
from rdkit.Chem import Descriptors, AllChem
import numpy as np

def featurize_smiles(smiles_list):
    """输入SMILES列表→输出描述符+指纹特征矩阵"""
    desc_names = [n for n,_ in Descriptors._descList]
    all_feats = []
    valid_idx = []
    for i, smi in enumerate(smiles_list):
        mol = Chem.MolFromSmiles(smi)
        if mol is None: continue
        # 描述符
        descs = [getattr(Descriptors, n)(mol) for n in desc_names]
        # 指纹(ECFP4)
        fp = AllChem.GetMorganFingerprintAsBitVect(mol, 2, 1024)
        fp_bits = [int(b) for b in fp]
        all_feats.append(descs + fp_bits)
        valid_idx.append(i)
    return np.array(all_feats), valid_idx

# 使用
X, valid = featurize_smiles(df['Drug'].tolist())
y = df['Y'].values[valid]
print(f"特征矩阵: {X.shape} (样本数×特征数)")

特征筛选三步走

from sklearn.feature_selection import VarianceThreshold

Day 4：hERG 心脏毒性预测——分类 + 不平衡处理

⏱️ 2小时 · 🎯 掌握分类任务全流程，重点处理类别不平衡

hERG 为什么是药物安全第一关？

hERG 钾离子通道被阻断 → QT间期延长 → 尖端扭转型室速 → 猝死。特非那定、西沙必利等药物因此被撤回。FDA 要求所有新药必须评估 hERG 风险。

类别不平衡处理（安全性预测的核心挑战）

# 大多数ADMET毒性数据集有毒分子只占5-15%→极度不平衡
from imblearn.over_sampling import SMOTE
from sklearn.utils.class_weight import compute_class_weight

# 方法1: SMOTE过采样——合成少数类样本（只对训练集！）
smote = SMOTE(random_state=42)
X_resampled, y_resampled = smote.fit_resample(X_train, y_train)

# 方法2: class_weight——让模型更关注少数类
weights = compute_class_weight('balanced', classes=[0,1], y=y_train)
model = RandomForestClassifier(class_weight={0:weights[0], 1:weights[1]})

# 评估重点：Recall（宁可误报也别漏掉有毒分子！）
from sklearn.metrics import recall_score
print(f"Recall(有毒类): {recall_score(y_test, y_pred, pos_label=1):.3f}")
⚠️ SMOTE 只对训练集做！测试集保持原始分布。SMOTE 生成的"虚拟样本"可能不化学合理，后续可用 GAN 等方法改进。
✅ 验收：分类模型 Recall > 0.8 合格，能解释为什么安全性预测看重 Recall 而非 Precision
